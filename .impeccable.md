## Design Context

### Users
Primary audience: podcasters using Discord to capture clean, editable multi-track recordings.
Secondary audience: gaming groups (especially TTRPG/D&D sessions) that want reliable session archives.

User context: they are typically setting up quickly before a live conversation/session and need confidence that recording will work without friction.

Job to be done: start, monitor, and retrieve dependable multi-track recordings with minimal setup and clear next steps.

### Brand Personality
Voice and tone should be clear, calm, and practical.

3-word personality: **delightful, calm, helpful**.

Emotional goals: users should feel **calm** and **trust** while using the interface.

Copy guidance: avoid flashy language; use regular, straightforward vocabulary.

### Aesthetic Direction
Keep the existing visual direction and component patterns already present in the project.

Theme: **dark mode only**.

Color direction: keep the current palette and established color usage in the page (including existing brand/accent colors).

Motion/accessibility: respect reduced-motion preferences and avoid unnecessary animation intensity.

### Design Principles
1. **Trust through clarity** — make key actions and system status obvious at a glance.
2. **Calm over hype** — prefer restrained visuals and plain language over flashy presentation.
3. **Delight in small moments** — subtle polish is welcome, but never at the expense of comprehension.
4. **Consistency with existing brand** — preserve current dark theme, palette, typography, and interaction patterns.
5. **Accessible by default** — honor reduced-motion preferences and maintain readable, high-contrast UI.
